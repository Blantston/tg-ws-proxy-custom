# Как загрузить исходники и собрать APK

1. Открой вкладку **Code** репозитория.
2. Нажми **Add file → Upload files**.
3. Перетащи архив `tg-ws-proxy-custom-1.2.4-source.zip` в корень репозитория. Архив находится в чате ChatGPT и его можно скачать по ссылке в сообщении.
4. Нажми **Commit changes**.
5. Открой вкладку **Actions** → **Build custom ARM32 APK** → **Run workflow**.
6. Дождись завершения. В успешном запуске открой **Artifacts** и скачай `tg-ws-proxy-custom-arm32`.

Сборка предназначена для ABI `armeabi-v7a` (твой POCO). APK будет подписан отдельным debug-ключом этого форка, поэтому он не обновит оригинальное приложение поверх — он устанавливается как отдельное приложение.

Если workflow завершится ошибкой, открой его лог и пришли ссылку на запуск.
